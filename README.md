# ربات مدیریت گروه ترندیفای – نسخه ۲

## نصب
1. در Cloudflare یک Worker بسازید و محتوای `updatemobser.js` را جایگذاری کنید.
2. **KV**: یک KV Namespace بسازید و با نام دقیق `KV` به Worker متصل کنید (Settings → Bindings).
3. **Variables/Secrets**:
   - `BOT_TOKEN` (الزامی)
   - `WEBHOOK_SECRET` (پیشنهادی؛ یک رشته تصادفی بلند فقط با حروف/اعداد/خط‌تیره/زیرخط)
   - `OWNER_ID` (اختیاری؛ آیدی عددی شما برای دریافت گزارش خطا)
4. **Cron Trigger**: Settings → Triggers → Cron → عبارت `*/5 * * * *`
   (بدون آن، تبلیغات خودکار ارسال نمی‌شود و کپچای منقضی کسی را اخراج نمی‌کند.)
5. وب‌هوک را تنظیم کنید (آدرس و توکن‌ها را عوض کنید):

```
https://api.telegram.org/bot<BOT_TOKEN>/setWebhook?url=https://<WORKER>.workers.dev&secret_token=<WEBHOOK_SECRET>&allowed_updates=["message","edited_message","callback_query"]
```

6. ربات را در گروه **ادمین** کنید (حذف پیام، محدود/مسدود کردن کاربران، پین، تغییر اطلاعات گروه) و بنویسید `پنل`.

## نکات
- هر گروه تنظیمات جداگانه دارد؛ هر ادمین فقط گروه‌هایی را می‌بیند که در آن ادمین است.
- برای فروش به چند مشتری، بهتر است برای هر مشتری ربات + Worker + KV جدا بسازید.
- ضد فلود و کش ادمین/تنظیمات داخل حافظه Worker است (تا ۲۰ ثانیه تأخیر در اعمال تغییرات روی نمونه‌های مختلف Worker ممکن است).
- «بازکردن گروه» مجوزها را به حالت استاندارد برمی‌گرداند.
- روی پلن رایگان KV محدودیت ۱۰۰۰ نوشتن در روز وجود دارد؛ برای گروه‌های پرتردد پلن پولی (ارزان) پیشنهاد می‌شود.
